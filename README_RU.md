# KineForge — универсальный вычислитель движения

Экспериментальная версия 0.3.0. Единое ядро восстанавливает движения сочленённого тела по координатам ключевых поз. Паспорт тела задаёт геометрию и при наличии массы, центры масс, тензоры инерции. Общая оптимизация учитывает траектории и вращения; обратная динамика оценивает необходимые силы и моменты. Это пока не полноценная физическая симуляция: контактные реакции, трение, анатомические пределы и прямую динамику ещё предстоит реализовать.

Редактор независим. Все исходные игровые модели, их движения и производные паспорта исключены из открытой поставки. Пример генерируется математически. Команды запуска и статусы описаны в [README](README.md). Контракт: [FORMAT](docs/FORMAT.md). План работ: [ROADMAP](docs/ROADMAP.md).
