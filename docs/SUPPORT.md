# 0.7 Gamma — scheduled sticking contact tracking

`track` retains the Beta no-contact path for absent/empty schedules. An optional `supportSchedule` in **tracking options**, not the author keys, defines prescribed sticking point supports with half-open frame intervals `[startFrame, endFrameExclusive)`. The last frame may be included by using `timeline.end + 1` as the exclusive endpoint. Transitions occur at frame boundaries; active supports apply throughout each integration substep, including midpoint evaluation, with outgoing constraints checked before release. This is prescribed switching, not automatic detection. Existing legacy contact hints in a target must be explicitly converted by the caller; nonempty legacy hints are rejected, never silently ignored. No contact impulses, snapping, floor geometry, sliding, or auto-liftoff.

```json
{"schema":"kineforge.tracking.v1","fixedBase":false,"substeps":4,"kp":100,"kd":20,"maxKeyErrorMm":1,"supportSchedule":[{"id":"support1","bone":"root","localPointM":[0,0,0],"anchorM":[0,0,0],"normal":[0,0,1],"mu":0.5,"startFrame":1,"endFrameExclusive":8}]}
```

At each sampled state, solve `M a = tau + J^T f - bias` with zero floating-root actuation, declared joint torque caps, and forces represented as nonnegative coefficients of the existing inscribed 8-ray friction cones. The coupled acceleration-level constraints are `J a + Jdot v + 2 w J v + w^2 (point-anchor) = 0`. The latter terms stabilize small drift without moving or snapping the configuration. `w=min(20,0.1/dt)` in inverse seconds. Default gap/speed tolerance is 0.1 mm / 1 mm/s (options `supportGapToleranceM`, `supportSpeedToleranceMps`, maximum 5 mm / 50 mm/s). Both are enforced at samples, midpoints and outgoing endpoints. Contact with larger initial velocity is rejected; no impulse is invented. Uncovered intervals have zero contact force. A prescribed support can be absent even if the body intersects its old plane; there is no environment collider in this mode.

The allocation minimizes a regularized least-squares acceleration error (mixed translational and angular generalized units, heuristic scaling). Root tracking feedback enters the desired acceleration only, not an actuator. Unknowns are joint torques and ray coefficients; redundant equality rows are removed by SVD only when compatible. Linear feasibility is checked with HiGHS, then SLSQP solves the constrained objective. Ball motor norm constraints are convex inequalities. If SLSQP fails and only independent bounds are present, bounded least-squares with increasing equality penalties may return a feasible fallback, only after mandatory independent residual checks. This is not a global optimality certificate. Numerical nonconvergence is reported, not proof of physical impossibility. The inscribed cone may conservatively reject a true Coulomb-feasible force.

Per-frame reports contain applied actuation, named contact force vectors in N, normal/tangent components, equation residual (mixed N and Nm), stabilized acceleration residual in m/s², gap and speed, allocation method, and mass matrix condition. Summary records sampled maximum residuals and transitions, methods and error gates. An actuator at its limit is conservatively flagged for review. Reports do not certify internal joint loads if masses or contact geometry are inaccurate. Fixed base continues to mean an external fixture, so do not use it to claim a freely standing creature.

`TRACKING_CANDIDATE` is only a numerical replay within configured pose/orientation, support and actuator limits; it is not a game or whole-trajectory physical certificate. Prescribed initial velocity remains unchanged. The original authored keys are retained. No cross-time optimal control, contact timing optimization, joint range collision response or independent body-scale motion acceptance. The existing kinematic `solve` stage is not replaced by the new contact allocation.

Reproduce: `python -m unittest discover -s tests -v` and `python examples/support_benchmark.py support_benchmark.json`. Tests cover static load distribution, coupled motion, redundant constraints, friction, support release/switch, zero-speed recontact, rejected impact, arbitrary support normals and fallback residual verification. Private character audits are not included in public fixtures.
